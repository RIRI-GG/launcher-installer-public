# RIRI Launcher

Official releases for the **RIRI Launcher** — a cross-platform game launcher installer.

## Downloads

| Platform | File |
|----------|------|
| Windows | `riri-launcher-windows-x64.exe` |
| macOS | `riri-launcher-macos-x64` |
| Linux | `riri-launcher-linux-x64` |

All binaries are native images built with [GraalVM](https://www.graalvm.org/) — no Java runtime required.

## Verification

Each release includes:
- `checksums.txt` — SHA-256 checksums for all binaries
- `checksums.txt.asc` — GPG signature for the checksums file
- `version.json` — machine-readable release metadata
